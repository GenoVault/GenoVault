Compute on genomic data without ever decrypting it.

A marketplace where a clinic, biobank or individual puts a dataset to work without handing it over. Runs execute as multi-party computation over ciphertext, the owner's consent is checked on-chain before anything runs, and the encryption key never leaves the owner's browser.

Three guarantees, enforced by the system rather than by policy.

Computation over ciphertext

Data is secret-shared across MPC nodes; no node sees a record, and the operator holds no key. The key is created and kept in the owner's browser.

Consent as a condition of execution

Allowed uses, expiry and revocation live on-chain. A run outside them is refused by the program, including one sent straight to the chain, around the API.

Settlement by contribution

The number of records that entered a run is counted inside the computation, not declared by the owner. The split among several owners is not measured yet (M3).

Four steps, and where each is checked.

  1. The owner encrypts the dataset in the browser. The key stays there.
  2. The owner sets consent on-chain: purposes, buyer categories, expiry.
  3. A buyer orders a run. The program checks consent and refuses anything outside it.
  4. MPC nodes fold the ciphertext and reveal only the aggregate, above a cohort floor. An independent verifier checks the run against the chain.

Limits, said out loud.

  • No protection yet against attacks on model privacy. Membership inference and training-set reconstruction are not addressed; only a computation that returns a record by construction is refused. This is the largest gap.
  • Synthetic data only. No criterion shows fitness for real patient data.
  • No legal or regulatory review. Cryptography is not certification.
  • On-chain consent is technical enforcement, not a document an ethics committee recognises.
  • A fixed catalogue of recipes. Buyers cannot run their own code over the data.
  • Consent is per dataset, not per record inside someone else's dataset.
  • No fiat off-ramp, no mobile app, English only.

Questions.

Is this real patient data?

No. Every dataset is synthetic, and the system has not been through legal or regulatory review.

Can the operator read my data?

The key is created and kept in your browser; the platform never receives it. The nodes compute on secret shares.

What stops a run I did not allow?

The program checks consent before a run exists; without a run, the compute layer has nothing to execute (SC-004, SC-005).

Why hours for 10 000 records?

The cluster saturates at four concurrent computations. The time is a measured property of this setup (SC-003).
