# GenoVault

Маркетплейс медичних і геномних даних для навчання AI-моделей, у якому дані
жодного разу не залишають шифрування. Клініка, біобанк або окрема людина віддає
датасет у роботу, не віддаючи самих записів; згода власника є умовою виконання
обчислення, а не обіцянкою в договорі; плата за прогін ділиться між тими, чиї
дані в нього справді потрапили.

- **Обчислення над зашифрованим.** Прогін виконується багатостороннім
  обчисленням: дані розділені між вузлами так, що жоден вузол не бачить записів,
  а оператор платформи не має ключа за побудовою, а не за політикою.
- **Згода, яку не обійти.** Дозволені типи використання, заборонені цілі, строк
  і відкликання живуть ончейн. Прогін поза межами згоди не блокується
  інтерфейсом — він не виконується, бо обчислювальний шар не отримує доступу.
- **Розрахунок за внесок.** Кількість записів, що реально увійшли в прогін,
  рахується всередині обчислення, а не заявляється власником; нарахування
  дорівнює тому, що власник просив за фактично використаний обсяг.
- **Доказовість.** Журнал прогонів, згод і виплат звіряється з мережею
  незалежним скриптом, який не користується кодом платформи.

## Стек

pnpm workspaces · TypeScript strict · Anchor 1.0.2 · Arcium 0.14 (MPC) ·
Arcis 0.10 · Hono · Drizzle + Postgres · React + Vite · Privy · Biome · Vitest

## Команди

```bash
pnpm install
pnpm dev          # усі застосунки паралельно
pnpm test         # тести
pnpm lint         # Biome
pnpm typecheck    # tsc --noEmit
pnpm gate         # lint + typecheck + test
```

Ончейн-частина збирається в Linux-оточенні: Rust 1.97.1, Solana CLI 4.2.0,
Anchor 1.0.2. Локальний MPC-кластер піднімається окремим скриптом і потребує
Docker.

## Статус

Ранній етап. Дані в демонстрації **синтетичні**; система не проходила
регуляторної чи юридичної експертизи й не призначена для роботи зі справжніми
пацієнтськими даними.
